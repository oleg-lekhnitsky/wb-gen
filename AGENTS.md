# Export work

Before changing banner rendering, exporting assets, or importing banners into
Figma, read and follow [EXPORT_CONTRACT.md](EXPORT_CONTRACT.md).

Treat the saved app settings and the browser-rendered stage as authoritative.
Do not silently change typography, substitute fonts, or rebuild the layout by
eye to work around import problems. Report unsupported editable features and
verify the result against the browser rendering before claiming fidelity.
